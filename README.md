**🎾 Game Analytics: Unlocking Tennis Data with SportRadar API**

This project is a tennis analytics web application built with Streamlit, Pandas, and MySQL Connector, designed to provide real-time insights into tennis players, competitions, and country-wise performance. 
The data is extracted from the SportRadar API and stored in a MySQL database, allowing for seamless query execution and interactive data exploration.

**🔍 Key Features:**

✅ Homepage Dashboard – Displays key statistics, including the total number of competitors, number of countries represented, and the highest points scored by a competitor.

✅ Search & Filter Competitors – Allows users to search for players by name and filter results based on rank, country, or points.

✅ Competitor Details Viewer – Provides detailed information on selected players, including their rank, movement, competitions played, and country.

✅ Country-Wise Analysis – Shows the total number of competitors per country and their average points.

✅ Leaderboards – Highlights the top-ranked competitors and players with the highest points.



With an intuitive interface and real-time MySQL queries, this project helps users explore tennis data effortlessly, making it a useful tool for tennis enthusiasts, analysts, and researchers.
